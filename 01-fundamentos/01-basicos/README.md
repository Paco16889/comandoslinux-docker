# 01 — Básicos

Comandos esenciales para orientarte en la terminal.

> **Cómo leer la sintaxis:** `<algo>` = lo sustituyes tú (no escribas `<` `>`).  
> `[algo]` = opcional (no escribas `[` `]`).  
> Explicación completa: [Cómo leer la sintaxis](../../README.md#cómo-leer-la-sintaxis-muy-importante).

## Orden recomendado

1. [pwd](pwd.md) — dónde estoy
2. [ls](ls.md) — qué hay aquí
3. [cd](cd.md) — cambiar de directorio
4. [clear](clear.md) — limpiar la pantalla
5. [echo](echo.md) — imprimir texto
6. [date](date.md) — fecha y hora
7. [man](man.md) — manual de un comando
8. [help](help.md) — ayuda de builtins de la shell
9. [history](history.md) — comandos que ya ejecuté
