# 03 — Lectura de texto

Ver, filtrar y contar el contenido de ficheros de texto.

> **Cómo leer la sintaxis:** `<algo>` = lo sustituyes tú (no escribas `<` `>`).  
> `[algo]` = opcional (no escribas `[` `]`).  
> Explicación completa: [Cómo leer la sintaxis](../../README.md#cómo-leer-la-sintaxis-muy-importante).

## Orden recomendado

1. [cat](cat.md) — mostrar (o concatenar) ficheros enteros
2. [less](less.md) — leer con scroll (ficheros largos)
3. [head](head.md) — primeras líneas
4. [tail](tail.md) — últimas líneas / seguir un log
5. [wc](wc.md) — contar líneas, palabras, bytes
6. [grep](grep.md) — buscar texto / patrones
7. [sort](sort.md) — ordenar líneas
8. [uniq](uniq.md) — quitar o contar líneas duplicadas
9. [cut](cut.md) — extraer columnas/campos
10. [diff](diff.md) — comparar dos ficheros
