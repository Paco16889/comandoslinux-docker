# 02 — Ficheros y directorios

Crear, copiar, mover, borrar y localizar ficheros y carpetas.

> **Cómo leer la sintaxis:** `<algo>` = lo sustituyes tú (no escribas `<` `>`).  
> `[algo]` = opcional (no escribas `[` `]`).  
> Explicación completa: [Cómo leer la sintaxis](../../README.md#cómo-leer-la-sintaxis-muy-importante).

## Orden recomendado

1. [mkdir](mkdir.md) — crear directorios
2. [touch](touch.md) — crear ficheros vacíos / actualizar fecha
3. [cp](cp.md) — copiar
4. [mv](mv.md) — mover o renombrar
5. [rm](rm.md) — borrar ficheros y directorios
6. [rmdir](rmdir.md) — borrar directorios vacíos
7. [ln](ln.md) — enlaces simbólicos y duros
8. [find](find.md) — buscar por nombre, tipo, fecha…
9. [tree](tree.md) — ver el árbol de directorios (si está instalado)
