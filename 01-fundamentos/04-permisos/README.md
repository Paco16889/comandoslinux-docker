# 04 — Permisos

Quién puede leer, escribir o ejecutar ficheros y directorios.

> **Cómo leer la sintaxis:** `<algo>` = lo sustituyes tú (no escribas `<` `>`).  
> `[algo]` = opcional (no escribas `[` `]`).  
> Explicación completa: [Cómo leer la sintaxis](../../README.md#cómo-leer-la-sintaxis-muy-importante).

## Orden recomendado

1. [leer-ls-l](leer-ls-l.md) — entender la salida de `ls -l`
2. [chmod](chmod.md) — cambiar permisos
3. [chown](chown.md) — cambiar dueño y grupo
4. [chgrp](chgrp.md) — cambiar solo el grupo
5. [umask](umask.md) — permisos por defecto al crear
6. [id](id.md) — tu usuario, grupos y IDs (puente a sistema)
7. [sudo](sudo.md) — ejecutar como administrador (introducción)
