# 07 — Docker Desktop (Linux)

App con **GUI** que, en Linux, arranca un motor dentro de una **VM** y usa el contexto `desktop-linux`.  
En esta guía el camino principal sigue siendo [Engine](../00-introduccion/instalacion-engine.md); Desktop es **opcional** y va **después**.

> **Estado:** Listo.  
> Fuentes: [Install Desktop on Linux](https://docs.docker.com/desktop/setup/install/linux/), [Ubuntu](https://docs.docker.com/desktop/setup/install/linux/ubuntu/), [Debian](https://docs.docker.com/desktop/setup/install/linux/debian/), [Fedora](https://docs.docker.com/desktop/setup/install/linux/fedora/), [Arch (experimental)](https://docs.docker.com/desktop/setup/install/linux/archlinux/).
