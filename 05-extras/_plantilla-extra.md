# Plantilla para extras (referencia)

Al rellenar cada extra, usa esta estructura (igual que el resto de la guía):

1. Título + qué es (1–2 frases)  
2. Aviso de sintaxis (`<>` / `[]`) + enlace al README raíz  
3. Ideas previas (tabla corta)  
4. Instalación (apt Mint/Ubuntu/Debian, dnf, pacman; Flatpak si aplica)  
5. Sintaxis  
6. Ejemplos (muchos, con `<marcadores>`)  
7. Errores frecuentes  
8. Relacionados  

Los ficheros marcados “Por rellenar” empiezan con un esqueleto mínimo.
