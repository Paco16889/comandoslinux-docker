# 07 — Ejercicios

Actividades prácticas para **aplicar** lo del tutorial.  
Hazlas **después** de leer el bloque correspondiente (no al revés).

> **Cómo leer la sintaxis:** `<algo>` = lo sustituyes tú · `[algo]` = opcional.  
> Guía: [Cómo leer la sintaxis](../README.md#cómo-leer-la-sintaxis-muy-importante).

> **Estado:** Listo (enunciados + soluciones).

## Cómo usar esta carpeta

1. Estudia el bloque del temario (enlace en cada ficha).  
2. Abre el enunciado y haz las tareas en tu Linux (terminal real).  
3. Comprueba con la sección *Comprueba* de cada ejercicio.  
4. Si te atascas: mira primero las **pistas** del enunciado; las **soluciones** al final (carpeta aparte).

No copies a ciegas la solución: el objetivo es practicar.
