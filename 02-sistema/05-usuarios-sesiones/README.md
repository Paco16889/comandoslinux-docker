# 05 — Usuarios y sesiones

Identidad en el sistema, sesiones abiertas y gestión básica de cuentas.

> **Cómo leer la sintaxis:** `<algo>` = lo sustituyes tú (no escribas `<` `>`).  
> `[algo]` = opcional (no escribas `[` `]`).  
> Explicación completa: [Cómo leer la sintaxis](../../README.md#cómo-leer-la-sintaxis-muy-importante).

## Orden recomendado

1. [whoami](whoami.md) — quién soy
2. [who-w-users](who-w-users.md) — quién está conectado
3. [last](last.md) — historial de logins
4. [su](su.md) — cambiar de usuario
5. [sudo](sudo.md) — ejecutar con privilegios (ampliación)
6. [passwd](passwd.md) — cambiar contraseña
7. [useradd-usermod-userdel](useradd-usermod-userdel.md) — alta/baja/modificación de usuarios
8. [groupadd-groupdel](groupadd-groupdel.md) — grupos
9. [exit-logout](exit-logout.md) — cerrar sesión / salir de la shell
