# 11 — Avanzado (introducción)

Herramientas que verás mucho “en la vida real”, explicadas **desde cero**.  
No hace falta dominarlas todas de golpe: úsalas como siguiente escalón tras scripts y pipes.

> **Cómo leer la sintaxis:** `<algo>` = lo sustituyes tú · `[algo]` = opcional.
